# Esquinas Florales v4 — Prompts Completos

**Reglas invariables**: Lilium candidum = flor principal siempre. Composición en L estricta. Fondo transparente PNG. Watercolor botánica. Ramas finas como líneas de lápiz.

**Keywords de tamaño**: `large prominent blooms`, `close-up botanical view`, `oversized lily blooms`, `flowers filling the frame`, `bold floral arrangement`

**Negative prompt estándar (Midjourney)**:
```
--no white fill solid background rectangular frame dark colors bold neon vibrant
geometric modern cartoon centered symmetrical sunflowers tulips diagonal sweep
centered bouquet oval arrangement small flowers tiny blooms distant flowers
```

## Tips de iteración

- **Flores aún pequeñas en DALL-E**: Añadir al inicio `"Extreme close-up watercolor botanical view."`
- **L no se mantiene en MJ**: Añadir antes de `--no`: `strict L-shaped composition only, one arm horizontal along bottom edge, one arm vertical along left edge, NO diagonal sweep, NO centered bouquet`
- **Color secundario muy saturado**: Añadir `muted, slightly desaturated, soft watercolor tones`
- **Lirios no reconocibles**: Añadir `Lilium candidum, trumpet-shaped white lily flowers with visible stamens, clearly recognizable lily blooms`
