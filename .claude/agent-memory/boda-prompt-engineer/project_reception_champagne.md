Generados prompts para ilustración de copas de champagne en sección Reception.
Archivo destino sugerido: `assets/images/florals/champagne-flutes.png`

El estilo sigue la misma línea que las esquinas florales: watercolor botanical illustration,
fondo transparente PNG, paleta ivory cream / pale blush / dorado champagne / sage green.

Variación A (Champagne Flutes clásicas): dos copas estrechas tipo flauta con burbujas, flores silvestres entrelazadas
Variación B (Copas de vino elegantes): dos copas de vino con rosas blancas y eucalipto
Variacion C (Copas con corona floral): copas rodeadas de corona floral suelta en diagonal

**Why:** La sección Reception necesita un ícono decorativo representativo de la celebración. Las copas de champagne complementan las esquinas florales sin duplicarlas.
**How to apply:** Si el usuario pide ajustes a estos prompts, usar la guía de iteración rápida de las esquinas (en romantic-floral-prompts.md). Mantener negative prompt estándar. Asegurarse de que el estilo acuarela y la paleta sean coherentes con lily-corner.webp.
